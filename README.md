###  Projects

- **[sysgaze](https://github.com/focuzd/sysgaze)**: A zero-dependency syscall tracer for x86-64 Linux, written from scratch in C23 and linking only to libc. It follows forks/clones/execs, decodes common syscall arguments, outputs text or NDJSON, and has an optional raw seccomp-BPF fast path. 
- **[rv-sparse-challenge-solution](https://github.com/focuzd/rv-sparse-challenge-solution)**: Dense→CSR conversion and sparse matrix-vector multiply in C, written for the RISC-V rv-sparse LFX Mentorship coding challenge.
- **[strace-clone](https://github.com/focuzd/strace-clone)**: An earlier ptrace-based syscall tracer that led to sysgaze.
